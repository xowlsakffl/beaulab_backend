# 카테고리와 앱 메뉴

## 두 기능의 차이

**카테고리 관리**는 업무 데이터를 분류하는 기능입니다. **앱 메뉴 관리**는 사용자가 여러 업무의 콘텐츠를 한 주제로 찾아보는 연결 기능입니다.

예를 들어 이벤트의 '눈'과 병의원 진료과목의 '눈'은 이름이 같아도 서로 다른 카테고리입니다. 이벤트 이름을 '눈 성형'으로 바꿔도 병의원의 이름은 바뀌지 않습니다. 앱 메뉴 '눈'에 두 카테고리를 각각 연결하면 한 메뉴에서 이벤트와 병의원을 함께 조회할 수 있습니다.

## 업무별 분류

| 업무            | 구조                                | 코드상의 도메인              |
| --------------- | ----------------------------------- | ---------------------------- |
| 병의원 분과     | 단일 단계                           | `HOSPITAL_DEPARTMENT`        |
| 병의원 진료과목 | 단일 단계                           | `HOSPITAL_SUBJECT`           |
| 의료진 진료분야 | 단일 단계                           | `DOCTOR_SUBJECT`             |
| 이벤트          | 성형·쁘띠의 최대 3단계, 기획전 별도 | `HOSPITAL_MEDICAL`           |
| 후기            | 후기 분류 트리                      | `HOSPITAL_REVIEW`            |
| 동영상          | 동영상 분류 트리                    | `HOSPITAL_VIDEO`             |
| 토크·평가       | 각각 단일 단계                      | `TALK / HOSPITAL_EVALUATION` |

`HOSPITAL_MEDICAL`은 현재 이벤트 분류의 기술 식별자로 남아 있습니다. 문자열만 보고 병의원 진료과목과 같은 데이터라고 해석하지 않습니다. 뷰티 관련 도메인 상수와 서버 조회는 남아 있지만 현재 병의원 중심 관리 화면의 범위와 구분합니다.

## 사용 방법

1. 대상 업무를 선택해 카테고리 이름과 사용 여부를 관리합니다.
2. '사용'은 신규 등록·수정에서 선택 가능한지를 정합니다. 상위 분류가 사용 중지이면 하위도 신규 선택이 제한됩니다.
3. 사용을 중지해도 기존 콘텐츠와 연결된 ID를 삭제하거나 다른 카테고리로 바꾸지 않습니다.
4. 앱 메뉴에서 성형·쁘띠 메뉴를 구성하고 연결할 업무 카테고리를 선택합니다.
5. 앱 메뉴 공개 여부는 사용자 메뉴의 노출을 정합니다. 업무 카테고리의 신규 선택 가능 여부와 다른 목적입니다.

신규 선택을 중지했다고 이미 등록된 콘텐츠가 앱 검색에서 자동으로 사라지는 것은 아닙니다. 공개 콘텐츠의 노출은 메뉴 연결과 각 콘텐츠의 공개·검수·신고 조건을 함께 확인합니다.

## 데이터 관계

`categories`의 ID는 업무별 분류를 식별합니다. 일반 콘텐츠 연결은 다형 `category_assignments`를 사용하고 대표 카테고리를 별도로 표시합니다. 병의원 분과는 기존 `hospitals.department` 코드와 연결되는 예외입니다.

`category_topics`는 앱 메뉴, `category_topic_links`는 메뉴와 업무 카테고리의 연결입니다. 일부 콘텐츠는 `category_topic_contents`로 직접 연결할 수 있습니다. 기획전 등은 일반 분류 트리와 똑같다고 가정하지 않습니다.

앱 메뉴에 상위 카테고리를 연결하면 조회 시 하위까지 확장합니다. 이름 일치로 다른 업무 카테고리를 자동 연결하지 않습니다.

## 변경과 보호 조건

- 이름 수정과 같은 부모 안의 순서 변경은 기존 콘텐츠 ID 연결을 유지합니다.
- 상위 이동은 같은 업무·그룹 안에서만 가능하며 자기 자신·자손·깊이 초과를 막습니다.
- 콘텐츠·단가·예약이 연결된 하위 트리는 이동을 제한합니다. 단순 이름 수정과 구별합니다.
- 하위 분류, 콘텐츠 사용, 앱 메뉴 연결 등이 남아 있으면 삭제를 제한합니다.
- 유효한 광고 예약에 쓰이는 분류의 사용·노출 변경은 예약 보호 규칙을 따릅니다.
- 버전 비교와 잠금으로 다른 관리자의 변경을 덮어쓰지 않습니다.
- 공개 조회는 승인·운영 상태, 공개 여부, 비밀글, 신고 자동차단·노출중지를 도메인별로 검사합니다.

## 권한과 구현 경계

조회·관리·상태 변경을 서버에서 검증합니다. 화면의 사용 토글과 메뉴 공개 토글은 다른 데이터를 바꿉니다. 과거 사용처 설정용 노출 컬럼은 호환 코드에 남아 있으나 현재 화면에서는 업무 카테고리와 앱 메뉴를 구분해 조작합니다.
