# 운영 정책 설정

## 금지어

회원 작성물에서 허용하지 않는 표현을 검사합니다. 단어·적용 영역·일치 방식·예외 표현·변형 검사를 별도 값으로 저장합니다.

현재 관리 UI는 **한 번에 한 단어 등록**을 기준으로 합니다. 서버에는 최대 200개 분석을 지원하는 내부 입력 로직이 남아 있지만, 한 행에 여러 금지어를 합쳐 저장하는 의미는 아닙니다.

| 설정                        | 동작                                                       |
| --------------------------- | ---------------------------------------------------------- |
| 포함 검사 `CONTAINS`        | 더 긴 단어·문장 안의 해당 표현도 찾음                      |
| 독립 표현 검사 `STANDALONE` | 앞뒤에 문자·숫자·결합 문자가 붙으면 일치에서 제외          |
| 변형 검사                   | 글자 사이 공백·일부 기호가 최대 2개 끼어든 형태도 검사     |
| 예외 표현                   | 금지어를 포함하는 더 긴 허용 표현. 해당 출현 범위에만 적용 |
| 적용 영역                   | REVIEW, TALK, EVALUATION, COMMENT, NICKNAME                |

대소문자·유니코드 호환형·일부 보이지 않는 문자를 정규화합니다. 예외 표현이 한 번 나왔다고 같은 문장 안의 다른 금지어까지 모두 허용하지 않습니다. 정규표현식을 운영자가 직접 입력하는 기능은 아닙니다.

저장 후 다음 작성 요청부터 사전을 읽으며 기존 콘텐츠를 일괄 수정·재검사하지 않습니다. 문장 검사는 등록 정책의 동작을 확인하는 기능이고 게시물 저장이 아닙니다.

**실제 연결 범위:** 사용자 후기·토크 작성, 후기·토크 댓글 작성, 닉네임 변경·자동 생성에서 검사합니다. EVALUATION 적용 영역은 정의되어 있지만 현재 평가 작성 경로의 검사 호출은 확인되지 않습니다. '모든 글쓰기에서 이미 차단한다'고 안내하면 안 됩니다.

## 자동 닉네임

활성 형용사 1개와 활성 명사 1개를 공백 없이 조합합니다. 기본 조합에는 숫자를 붙이지 않고 중복일 때만 숫자 접미사를 허용합니다.

- 단어는 완성형 한글 1~20자이며 숫자·기호·공백을 넣지 않습니다.
- 단어 등록 분석은 공백·쉼표 등으로 분리하고 최대 200개, 같은 유형의 중복을 구분합니다.
- 삭제된 회원도 닉네임 고유 제약에 포함되므로 기존 이름을 재사용하지 않습니다.
- 금지어 NICKNAME 검사를 통과한 조합만 사용합니다.
- 사용할 형용사·명사가 없거나 조합이 부족하면 오류를 반환합니다. 임의의 영문·고정 이름으로 대체하지 않습니다.
- 단어 수정·사용 중지는 앞으로 생성할 이름에 적용되며 기존 회원 닉네임은 변경하지 않습니다.

생성기와 회원 생성 Action이 있어도 일반 가입 화면·API 전체가 연결됐다는 뜻은 아닙니다.

## 공지와 운영 자료

공지사항은 대상·게시 상태·기간과 본문·첨부를 관리합니다. 에디터 임시 이미지는 게시물에 연결된 파일과 구별하며 정리 스케줄이 있습니다. 관리자가 입력한 HTML도 허용 규칙에 따라 정제합니다.

카테고리·앱 메뉴는 [별도 기준서](categories.md), 직원 수신 설정은 [알림](notifications.md), 챗봇 운영시간·문구·매크로는 [챗봇](chatbot.md)에 둡니다. '운영 설정'이라는 메뉴 이름만으로 권한·보관·상태를 하나로 묶지 않습니다.
