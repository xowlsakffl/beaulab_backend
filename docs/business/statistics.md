# 통계와 집계 기준

통계마다 시간 기준·대상·권한이 다릅니다. 이름이 비슷한 숫자를 같은 집계로 합치지 않습니다. 서버 기본 시간대는 [config/app.php](../../config/app.php)의 Asia/Seoul입니다.

## 메인 대시보드

| 영역             | 기준                                                               |
| ---------------- | ------------------------------------------------------------------ |
| 현재 업무        | 직원이 조회·처리할 수 있는 도메인 업무. 각 도메인 원래 상태를 유지 |
| 상담 현황        | 연결 대기를 우선하고 본인 담당 진행 상담을 표시                    |
| 운영 현황        | 이벤트 DB·비대면·리얼모델의 생성일 기준 접수 수                    |
| 포인트 거래 현황 | 이번 달 1일 00시부터 현재까지의 완료 원장                          |

운영 현황 UI는 오늘·7일·30일을 선택합니다. 선택 기간은 포인트 거래 현황에 적용하지 않습니다. 날짜별 없는 값은 0으로 채우고, 미래 시점은 현재 시각까지 제한합니다.

대시보드 API에 신규 회원 지표가 남아 있지만 현재 운영 현황 차트는 이를 제외합니다. API의 전체 응답과 화면 시리즈는 같은 목록이라고 가정하지 않습니다.

포인트 집계는 완료 Operation에 연결된 Transaction의 생성일과 Entry 금액을 기준으로 합니다. 화면의 충전·소진·환불·적립·회수는 유상·서비스 잔액 종류에 맞게 표시합니다. 해당하지 않는 조합의 `—`와 실제 거래가 0인 `0`을 구별합니다. REVERSAL 순액은 API에 별도로 반환되며 5개 업무 행으로 임의 합치지 않습니다.

## 충전금 현황

- 연간 충전·소진·환불: 선택 연도의 완료 거래, 거래 생성일 기준.
- 월별 추이: 현재 월을 포함한 최근 6개월. 연도 선택과 동일 범위라고 보지 않습니다.
- 잔액: 현재 지갑의 유상·유상 예약·서비스 잔액 합계. 기간 내 거래 합계와 다릅니다.
- 사용 상위 병의원: 완료 USAGE의 DEBIT 항목을 병의원별 합산. 유상·서비스 필터와 선택 기간을 적용합니다.
- 카테고리별 신청 비중: 이벤트 DB와 이벤트 대표 카테고리의 연결 기준입니다. 거래 비용 비중이 아닙니다.

전체 거래 내역의 기본 목록은 특정 대상·검색이 없는 경우 USAGE를 제외하는 별도 조회 정책이 있습니다. 따라서 기본 목록 건수와 모든 소진 통계가 바로 일치하지 않을 수 있습니다.

## 일반회원 현황

현재 회원 수·가입 경로는 정상·정지 회원 기준입니다. 차단·탈퇴를 포함하는 전체 누적 가입자 수와 다릅니다.

신규 가입은 생성 시각 기준이며 삭제된 회원도 포함합니다. 오늘은 어제 같은 시각, 월 방문은 이전 달 같은 경과 시점과 비교합니다. 이전 값이 0이라 증감률을 계산할 수 없는 경우 실제 0%와 구분합니다.

방문자는 `site_visit_sessions`의 세션 수입니다. 고유한 사람 수·IP 수가 아닙니다. 일별 최근 30일, 월별 최근 12개월을 표시합니다. 수집 데이터가 없는 상태와 수집된 0건을 구분합니다.

## 챗봇 통계

상담은 `requested_at`, 이용 이벤트는 `occurred_at`이 선택 기간에 속하는 기록을 집계합니다. 현재 구현은 앱·DB 시간대가 Asia/Seoul인 구성을 전제로 날짜·요일·시간대를 구합니다.

| 지표                | 정의                                                         |
| ------------------- | ------------------------------------------------------------ |
| 요청                | 기간 내 요청한 상담 수                                       |
| 연결                | 그 요청 중 연결 시각이 있는 상담 수                          |
| 종료·취소·만료·진행 | 요청 집합의 현재 상태·종료 사유 기준                         |
| 대기시간            | 요청부터 연결까지의 초                                       |
| 첫 응답시간         | 연결부터 직원의 첫 일반 텍스트 응답까지. 자동 연결 인사 제외 |
| 상담시간            | 연결부터 종료까지. 종료된 상담 표본                          |
| 중앙값·P90          | 정렬된 초 단위 표본의 nearest-rank 방식                      |
| 요일 × 시간대       | 요청 시각의 요일·시간별 건수                                 |
| 질문 Top            | 질문 조회 이벤트 수 또는 상담 문맥 질문별 요청 수            |
| 병의원 Top          | 해당 기간 요청·연결·이용 이벤트 집계                         |

현재 진행 중 상담이 나중에 종료되면 같은 과거 기간의 상태별 수치가 달라질 수 있습니다. 종료일 기준 별도 코호트 통계가 아닙니다. 위젯 열림·질문 조회는 이벤트 건수이며 고유 사용자 전환율로 해석하지 않습니다.

실시간 대기 수는 선택 기간 통계와 별도 현재값입니다. 이용 이벤트 180일 보관 정책 때문에 오래된 질문 조회 통계는 상담 기록과 보존 범위가 다를 수 있습니다.
